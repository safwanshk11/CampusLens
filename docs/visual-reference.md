# Visual Reference

## Inspiration

**Clinch** — <https://github.com/balajisabk32-cmd/Clinch>

Clinch was studied **only as design-language inspiration**. No branding, page composition, assets,
copy or source code were taken from it, and nothing was recreated pixel for pixel.

> We borrowed principles such as dimensional glass surfaces, floating navigation, ambient depth and
> choreographed interaction, while designing an original visual identity and component architecture
> for CampusLens.

## Principles studied

- Floating liquid-glass surfaces
- Multi-layer visual depth
- Detached navigation
- Ambient light fields
- Subtle grain
- Animated specular highlights
- Double-bezel containers
- Kinetic typography
- Scroll-driven choreography
- Restrained 3D depth
- Sophisticated hover interactions
- Asymmetric editorial layouts
- High-quality responsive behaviour

## What is original to CampusLens

| Area | CampusLens approach |
|---|---|
| Identity | CampusLens name; lens-ring "C" mark with campus columns and a top-left glint; Geist + Instrument Serif wordmark |
| Palette | Cool canvas (`#F4F7FB`), deep ink, ice / azure / indigo-mist environment light, with contrast-corrected text tokens |
| Lighting model | One documented top-left light source that governs every edge, glare, sheen and shadow |
| Glass construction | PRISM anatomy: masked specular edge, sheen, transform-only glare, three levels plus ink glass, backdrop-root and nesting rules |
| Visual regimes | Cinematic vs Intelligence, enforced by route groups |
| Hero composition | Stair-stepped three-line headline, search island overlapping the headline tail, illustrative data chips on parallax planes, oversized lens ring echoing the mark |
| Kinetic moment | "Fifteen tabs / five conflicting numbers" scroll-reading statement |
| Scroll story | Discover → Compare → Shortlist sticky glass sheets; Search → Inspect → Compare → Save connector |
| Navigation | Transform-only morph using container-query units |
| Components | Built from scratch for college discovery: college card contract, compare check, save toggle, compare tray, search island |
| Motion | Five-curve vocabulary shared by CSS, GSAP (CustomEase) and Framer Motion |

## Guardrails applied

- No stock photography, no generated raster logos, no emoji as interface icons.
- No fake testimonials, user counts or college statistics. Illustrative values are labelled.
- No cursor replacement and no scroll hijacking. Native keyboard and touch scrolling are preserved.
